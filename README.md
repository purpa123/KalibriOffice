# 📁 KalibriOffice

**Your personal open‑source office suite**  
Built with Python and CustomTkinter.

---

## ✨ Features

- **KalibriWord** – text editor with tabs, images, search, bold/italic/underline, and `res//` commands.
- **KalibriTable** – spreadsheet editor (`.xlsx`) with rows/columns management.
- **KalibriShow** – presentation editor with slides, backgrounds, images, and full‑screen slideshow.
- **KalibriConsole** – embedded terminal with Python execution, history, aliases, and `res//` commands (including rainbow 🌈).
- **PyBash** – Russian‑language Bash‑like interpreter with variables, sub‑shells, redirections, and pipelines.

> **Note:** PyBash interface and messages are in Russian.  
> A warning will appear when launching it from the launcher.
